# Agent guidelines (web)

The marketing site mirrors the `rumor` app. Two things are generated from the app
at build time, not authored here:

- **Version.** `scripts/sync-version.mjs` reads `rumor/Cargo.toml` and writes
  `src/generated/version.ts`. Components import `VERSION` from `src/consts.ts`.
  Never hardcode a version string in this tree; edit `rumor/Cargo.toml` (or let
  release-please bump it).
- **The `/docs` page.** `scripts/sync-version.mjs` copies
  `rumor/docs/AGENTS_GUIDE.md` into `src/generated/agents-guide.md`, which
  `src/pages/docs.astro` renders. Never edit the copy; edit the guide in the
  rumor crate.

`src/generated/` is gitignored and regenerated by the `sync` script, which runs
as a `pre` step before `dev` and `build` (see `package.json`). Run
`npm run sync` if you need to refresh it by hand.

The feature rows in `src/pages/index.astro` and the demo scenes in
`src/components/terminal/scenes.ts` are hand-authored marketing that restates app
keybindings and flags. When the app changes one of those, update it here too.
